Una **abstención** significa que no se pudo asignar nivel con las reglas o la evidencia
disponibles. Una **inválida** incumple las reglas de salida. **No aplica** significa que
el grupo no corresponde a esa pantalla. Ninguna de estas opciones equivale a un cero.

## Ejemplos para mostrar el avance

- **G1:** 23 de 24 páginas recibieron 0. Conservamos esa concentración y señalamos que
  no permite comparar bien las páginas. No movimos los cortes para repartir puntajes.
- **G3:** C17 repitió 0 en las cinco respuestas, pero todas advirtieron falta de evidencia.
  El nivel se mantuvo; eso no basta para darlo por correcto.
- **G4:** S07 debía distinguirse solo por color. Las cinco respuestas dieron 4 en vez
  del 3 previsto, al reconocer también un peso tipográfico que el diseño no respaldaba.
  Conservamos el desacuerdo para revisarlo con Camilo.
- **G5:** probamos el caso que nombra las etapas, pero no marca la actual. Recibió el
  nivel 1 que habíamos propuesto. También comprobamos ejemplos de niveles 3 y 4 en
  horizontal y vertical. Son expectativas nuestras, todavía no calificaciones expertas.
- **G6:** las 120 abstenciones muestran un límite importante del procedimiento actual.
  No las contamos como aciertos ni como puntajes estables.
